## 🚀 **Flagship Product Line — SnapDock**

### **SnapDock — Local‑First Markdown Workspace**  
A clean, predictable writing environment built for long‑term use. Designed for writers who value clarity, stability, and a distraction‑free workflow.  
**Status:** Full Release • https://snapdock.app

### **SnapDock‑Online — Online‑First Publishing Platform**  
A lightweight, browser‑based companion to SnapDock. Built for instant access, fast publishing, and a frictionless way to share your work from anywhere.  
**Status:** Early Beta • https://snapdock.app/snapdock-web/
