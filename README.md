## 📦 The Product Lines

### ⚡ The **Snap** Range
*The flagship suite of modern, distraction-free productivity tools.*
*   [**SnapDock**](https://github.com/zforddev/snapdock) — A minimalist Markdown editor for deep writing. (V3 in progress).
*   [**SnapBoard**](https://github.com/zforddev/snapboard) — Local-first Kanban for intentional planning.
*   *More coming soon...*

### ➕ The **Plus** Range
*The learning-focused utility range built for clarity and speed.*
*   [**MathPlus**](https://github.com/zforddev/mathplus) — A clean, Rust-based minimalist calculator.
*   [**SchedPlus**](https://github.com/zforddev/schedplus) — A Python-driven scheduler for automated workflows.
*   *More coming soon...*

### 📡 The Wildcard
*   [**StaxPing**](https://github.com/zforddev/staxping) — A dedicated personal passion project. A unique, unified interface for high-speed network diagnostics and clarity.
